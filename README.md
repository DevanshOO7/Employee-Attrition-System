# Employee Attrition Prediction and Analytics System

## 📌 Project Overview

The **Employee Attrition Prediction and Analytics System** is a machine learning-based project designed to predict whether an employee is likely to leave an organization.

The system analyzes employee-related factors such as **age, salary, job role, job satisfaction, overtime, work experience, and other workplace attributes** to identify patterns associated with employee attrition.

The project combines **Machine Learning, Backend Development, Frontend Development, and Analytics** to provide a complete system for HR-related decision making.

---

## 🎯 Objectives

- Predict whether an employee is likely to leave the organization.
- Identify important factors associated with employee attrition.
- Apply machine learning models to employee data.
- Provide useful insights for HR departments.
- Develop a complete system by integrating the ML model with backend and frontend components.

---

## 📊 Dataset

The project uses the **IBM HR Analytics Employee Attrition & Performance Dataset**.

- **Total Records:** 1,470 employees
- **Features:** 35 attributes initially
- **Target Variable:** `Attrition`
- **Target Classes:** `Yes` / `No`

The dataset contains information related to:

- Employee age
- Monthly income
- Job role
- Department
- Job satisfaction
- Overtime
- Years at company
- Work experience
- Work-life balance
- Performance rating
- Marital status
- And other employee-related factors
